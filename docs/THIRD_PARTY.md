# Third-party design references

Encore (`Rem01Gaming/encore`) was reviewed as an architectural reference for event-driven foreground game detection and automatic performance-profile switching. Encore is distributed under Apache License 2.0.

The current KB1001 implementation does not copy Encore's chipset tuning tables. KB1001 GPU control remains device-specific and based only on the interfaces already validated on the Allwinner A333 tablet.
